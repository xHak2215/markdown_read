# markdown_read
простая консольная программа для удобного просмотра `md` файлов с markdown разметкой

программа не поддерживает всех возможностей MarkDown но делает чтение в консоли более приятным 

**что поддерживается:**
`#` - заголовки любого уровня

`<br>` - перенос строки

`>` - цытаты со вложеностью

`** * ~~ __` - стили тектса: жырный, курсив, зачеркнутый, выделеный

`* - +` - списки

`\`\`\`` - выделеный код

`\`\`` - выдленая комнада
